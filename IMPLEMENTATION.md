# Implementation plan

This is the umbrella repository and project front door.

1. Keep `SPEC.md` in sync with the canonical specification.
2. Maintain `REPOSITORIES.md` as repositories are added or renamed.
3. Publish releases and release notes.
4. Maintain governance, maintainers, roadmap, and contribution guides.
5. Curate issues and discussions that span more than one repository.
6. Publish the project website and documentation links.
